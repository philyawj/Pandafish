  package's race tests after its archive/PGN fixes; those pass too.
- `go vet ./...`, native engine build and Linux/ARM64 cross-build: passed.
- `go run ./tools/research policy`: all 59 original engine/library files match
  tagged v0.18 after substituting the version in `main.go` and its handshake test.

- The source-policy test passes: no repository Python, shell or other-language

  every explicit retirement/document rewrite, and all 1,148 original files in
  the hashed release attachment. Raw research observations retain their hashes.
- Go decision checks reproduce every saved sharp-branch choice, tie, penalty,
  risk and per-turn result. Go mate checks verify 15 positive proof records
  (14 distinct FENs) and 59 saved negatives.
- Both Go scratch replays pass tests and build: the archived rejected
  independent-family candidate, and unchanged v0.18 with the archived quiet-mate
  proof test. These are restoration checks, not a new fit or strength sample.
- Publication-wording, path traversal, overwrite, unrecorded-evidence change,
  mate/escape/stalemate, integer truncation, unsafe tie and claimed-repetition
  controls pass. I check local links, Markdown table columns and staged source
  extensions before publication.
