# v0.19 release validation

This record covers release/tooling validation. Playing policy remains v0.18;
the UCI version becomes v0.19. The rejected fits remain inactive. No new
strength screen or live Lichess game is part of this release.

The original research evidence and all initial failures remain preserved. The
[research summary](../../docs/RESEARCH_V019.md) explains results and next steps.
## Correctness and tooling checks

- `go test -race ./...`: all five packages passed. The research package's race
  tests also pass after its archive/PGN fixes and factual-wording correction.
- `go vet ./...`, native engine build and Linux/ARM64 cross-build: passed.
- `go run ./tools/research policy`: all 59 original engine/library files match
  tagged v0.18 after substituting the version in `main.go` and its handshake test.
  New source is tooling/test policy; no learned model is active.
- The source-policy test passes: no repository Python, shell or other-language
  source remains, including script-name `.txt` copies. No language is hidden
  through GitHub attributes. The shell engine fixture is a Go test subprocess.
- The Go inventory audit verifies 11 inventories / 1,023 entries, including
  every explicit retirement/document rewrite, and all 1,148 original files in
  the hashed release attachment. Raw research observations retain their hashes.
- Go decision checks reproduce every saved sharp-branch choice, tie, penalty,
  risk and per-turn result. Go mate checks verify 15 positive proof records
  (14 distinct FENs) and 59 saved negatives.
- Both Go scratch replays pass tests and build: the archived rejected
  independent-family candidate, and unchanged v0.18 with the archived quiet-mate
  proof test. These are restoration checks, not a new fit or strength sample.
- Publication-wording, path traversal, overwrite, unrecorded-evidence change,
  mate/escape/stalemate, integer truncation, unsafe tie and claimed-repetition
  controls pass. Local links, Markdown table columns and staged source extensions
  are checked before publication. The final wording rule requires neutral,
  factual prose and rejects first-person voice in PR/release text.

Two initial replay failures remain preserved: the source overlay needed
a JSON fixture, and Git's PAX global commit-metadata entry needed explicit
handling. Focused controls cover both repairs in the Go replay tool. The original
failed logs remain alongside the successful logs. No experimental data, model,
fit gate or game was rerun to improve a result.

The first PGN-check attempt exposed a pinned-parser limitation: the declared
threefold draw was parsed with `NoOutcome`. That diagnostic remains preserved.
The PGN result tag and legal repetition eligibility were then checked
independently; all moves and lengths already agreed. A regression control covers
repetition claims and result mismatches. The library and saved game are unchanged.
Go builds also emitted
sandbox module-cache write warnings while returning success; both executables
were produced. No dependencies were installed or updated.
