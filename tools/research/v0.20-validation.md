# v0.20 release validation

v0.20 promotes the approved search-legality kernel. The
[candidate evidence](../benchmark/research/v0.20-search-legality/RESULTS.md)
retains its original development label, native UCI name, binary hash and all
150 standard-screen games. Release preparation changes only version identity
and its handshake expectation in playing source. Values, search eligibility,
ordering, TT policy, repetition and clocks are unchanged from the screened
candidate. The [research assessment](../../docs/RESEARCH_V020.md) preserves the
failed predecessors and next priorities.

## Source, tests and evidence

- [Source identity](validation/v0.20-release/source-identity.json) compares the
  release against tagged v0.19 plus the complete frozen candidate overlay,
  allowing only v0.19-to-v0.20 substitutions in `main.go` and `main_test.go`.
  Unrecorded root/library source additions are rejected. The reproducible Go
  checker is saved beside the result.
- [Release validation run](validation/v0.20-release/previous-run.txt) passes Go
  formatting, full race tests, vet and native build before smoke games. The
  release Linux/ARM64 cross-build passes too. Earlier 37,795 transition controls,
  128,000 independent attack comparisons and 325 exact-tree comparisons remain
  tied to the unchanged playing kernel.
- The [candidate evidence audit](validation/v0.20-evidence-audit.json) verifies
  14 inventories / 1,297 entries and all 1,148 original v0.19 attachment files.
  All raw candidate data and inventories remain byte-identical through release
  preparation. Current README/release/benchmark documentation hashes are updated
  explicitly in the existing migration mapping; original hashes and historical
  observations remain intact. The release audit verifies that mapping again.
- PR/release bodies pass the Go factual-wording checks. Local links, Markdown
  columns, source formatting and diff whitespace are checked before publication.
  All repository program/test/research source, including saved drivers, is Go.
