# v1.0 release validation

v1.0 promotes bounded protected queen-contact threat defense and marks a stable
engine milestone. Active development is paused to focus on other efforts.
GoPandaFish and other Panda Bots will use the engine on Lichess. Publication
does not start a client, deploy a bot or begin another experiment.

## Distribution and evidence limits

All six macOS/Linux/Windows amd64/arm64 targets build with CGO disabled,
`-trimpath` and `-buildvcs=false`. Only macOS ARM64 is runtime-tested on this
host. Each release archive includes the executable, LICENSE and
THIRD_PARTY_NOTICES.md. Binaries stay outside Git. Packaging verifies the merged
source against the prepared build inputs; the public build manifest records
the merged commit, source hashes, Go version, targets and asset identities.
SHA256SUMS covers the six archives and manifest. The archived
[Go asset builder](validation/v1.0-release/assets.go.txt) records that procedure.

The repository evidence audit verifies local records and historical document
transitions. The existing v0.19 external historical attachment is not downloaded
again during this release, so fresh external-attachment verification is not
claimed. Existing evidence stays in place under the
[storage policy](../../docs/EVIDENCE_STORAGE.md); future work uses leaner records.
