# Working on Pandafish

I keep this repository 100% Go: engine, tools, tests and research programs.
Do not add Python, shell or other language source, including disguised source
files or embedded script fixtures. Data, documentation and configuration are fine.

Start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
Use [the tools guide](tools/README.md), [benchmark guidance](tools/benchmark/README.md),
[recording guidance](tools/lichess/README.md), and [the backend note](docs/CHESS_SEARCH_BACKEND.md)
for the relevant work. Follow [RELEASING.md](RELEASING.md) for PRs and releases.

I write project explanations in first person. Never use the word "maintainer"
in PR titles/descriptions or release titles/notes. Preserve failed results and
distinguish functional changes from measured playing strength. Do not start
live games without explicit authorization.
